# 糖果屋 · 新都蜗牛巷

一个 2D 像素风的轻量模拟经营网页游戏原型。白天在蜗牛巷卖糖，其余时间骑摩托穿过新都送货。
纯前端、零依赖，双击 `index.html` 就能玩。

---

## 运行

```
直接双击 index.html
```

（也可以起个静态服务器：`npx serve .`。因为全部是传统 `<script>`，不需要打包，也没有 CORS 问题。）

想让手机 / 平板 / 同局域网的其它机器也能打开，用**内网监听**启动：

```
python -m http.server 5173 --bind 0.0.0.0
```

然后访问 `http://<本机内网 IP>:5173`。默认的 `--bind 127.0.0.1` 只有本机能连。
Windows 上如果别的设备连不上，需要在「Windows Defender 防火墙 → 允许应用通过防火墙」里
放行 Python（或直接放行 TCP 5173），并确认当前网络配置文件是「专用网络」。

## 操作

- **存档 / 读档**：右上角「存」或 `Ctrl+S` 打开面板，三个槽位随时存、随时读（覆盖要点两下确认）。
  每次行动与换阶段都会写自动存档，标题页的「继续上次」读的就是它；右上角「退」回标题，回之前会自动存一次。
- **面板**：点左侧标签切换；右侧「可以做的事」花行动点；右下角推进阶段。
- **柜台**：客人最多同时来 3 位，点左上角名字标签切换当前招呼的人。
  货架上有他要的就「交付」，缺货可以点「现做」用原料当场补一份，实在做不出就「婉拒」（掉点信誉）。
- **地图**：`WASD` / 方向键移动，`E` 互动；点空地会自己沿路走过去。
  - **潜入时**：`Shift` 蹲下走得慢、不容易被看见；`Q` 扔糖把守卫引开。
  - 手机上不需要键盘：走到门口会出现**可点的「进入 xx」按钮**（画布底栏上方）。
  - **点地点只是设目标**，不会自己走（避免误触白烧行动点）。定好目标后有三种方式出发：
    1. 点屏幕边缘的粉色箭头（写着「点我出发」）；
    2. 再点一次那个目标点的光圈；
    3. 点顶部导航卡上的**「自动走」**按钮。
    路上按任意方向键、或点「停下」立刻接管；到了目标会提示，行动点不够出发会直接被拦下并说明差多少。
  - 点地上的空地，人物会**沿 BFS 算出来的路线绕过去**（不会直线怼墙）；半路被挡住会按当前位置重算一条，走不通才提示。
  - `M` 摊开**全城地图**（也可以点右上角的小地图）。把鼠标放到任意地点上，底部会显示
    「去 N AP · 回 N AP」和够不够；点一下就把那儿设成导航目标。再按 `M` 或 `ESC`、或者点右下角的叉收起。
  - `Tab` 打开**车厢清单**，按地点分组列出这趟带的货、每样差多少、以及还有哪些订单没装车。
  - 地面上的粉色光点是导航路径（BFS 沿可走格子算的，会绕开建筑）。
    **亮着的部分是你这点行动点走得到的，变暗那一截就是走不到了**，末端有个红叉。骑到叉那儿就该回头。
  - 顶部「导 xxx · 去 N · 回 N AP」三档配色：粉色=够来回，黄色=去得了回不来，红色=连去都不够。
  - 行动点归零不会直接把你踢回去，会给你三个选择：**叫车**（40G，人不累）、
    **推车走回去**（不花钱，元气 -12）、**就地收工**。没送完的订单回到订单簿。
  - 右下角「结束这一趟」提前收工。

## 跑不远怎么办

行动点不是无限的，这几条路可以让你跑得更远：

1. **少装两单** —— 出货窗会直接算「这一趟来回要几 AP」，超了会标红并告诉你差多少。
2. **换车** —— 每辆车有 `apMul`：摩托 1.00、厢型车 0.85、小货车 0.72。
   也就是同样的 1 点行动点，摩托跑 110px，厢型车 129px，小货车 153px。换车不只是装得多，还能跑得更远。
3. **坐地铁** —— 每段扣 1 AP，另收 6G 车票，跨区还是比一路骑过去划算。首班 06:00、末班 23:00，早起准备（05:00）站台没开。先骑到最近的站，再地铁。
4. **公交 / 渡船** —— 公交总站有去旧城中心（2 AP / 12G）、城南（3 AP / 18G）、学院（4 AP / 24G）的电车；渔船码头可以搭船直接跨海到新岛站（3 AP / 45G），比绕跨海大桥快，但更贵。
5. **钻地下管网** —— 走到后院矮墙、中央广场、城南地道口这类有井盖的地点，先在菜单里「记下这个井盖」，之后从任意已探明的井盖下井就能直达。掀盖 1 AP、每段再 1 AP / 2 点元气，**不收钱也不查证件**：含烈酒或魔法糖浆的货过不了地铁，走这儿。车库页常驻管网图和剩下的出口线索。

线路（与需求文档一致，`data.js` 的 `METRO.graph`，**必须双向都写**）：

| 线 | 走向 | 相邻关系 |
|---|---|---|
| 1 号线 | 码头 — 旧城中心 — 新岛 | 码头↔旧城中心↔新岛 |
| 2 号线 | 旧城中心 — 城南 | 旧城中心↔城南 |
| 3 号线 | 蜗牛巷 — 旧城中心 — 学院 | 蜗牛巷↔旧城中心↔学院 |
| 4 号线 | 新岛 — 学院 — 城南 | 新岛↔学院↔城南 |

段数由 `Engine.metroDist()` 用**无向 BFS** 算（一端写了就算通），
所以同一条路来回价钱一定一样。北山墓地没有线路，只能骑车。

### 新岛安检：敏感货上不了地铁

新岛是议会的地盘，进岛要过安检机。**地铁站那台 X 光机会翻箱**，
货车道（跨海大桥）只验证件不拆箱——所以含**烈酒 / 魔法糖浆**的成品
（虹彩糖、威士忌酒心球、海盐焦糖酒心巧克力……）**坐不了地铁**，
那几单只能自己骑车带进去。

- 判定在**上车时**：目的地选新岛站、车厢里又有敏感货 → 该站变灰，标「安检 / 行李过不去」
- 敏感货清单不用手工维护：凡是配方里带 `wine` 或 `syrup` 的成品，自动算敏感货
- 店铺页买 **铅衬行李袋（1400G）** 之后可以照常坐地铁，X 光机看不出里面是什么

这不是惩罚，是给「送新岛」多一道路线选择：要么绕远骑车，要么花钱买袋子。
5. **半路叫车** —— 真的跑不动了，花 40G 回家，比硬走回去掉元气划算（元气影响制作成功率）。

## 熟人与口味

后场左侧的**「熟人」**页是这套经营系统的心脏。24 位客人每个人都有自己的一行账，
存在存档里，跟着你一起老：

| 记什么 | 怎么变 |
|---|---|
| 信任度 0–5 | 准时送到 +0.14；超时 −0.15（挑剔的地方按 `strict` 加倍）；退单 −0.35；柜台卖给他 +0.04（卖对了口味 +0.09） |
| 关系档位 | 生客（<1.8）→ 认识（<3.0）→ 熟客（<4.2）→ 老主顾 |
| 累计消费 / 小费 | 每次交付和柜台成交都累加 |
| 下单 / 准时 / 超时 / 退单 | 用来看这个人的准时率 |
| 偏好口味 | 写在 `data.js` 的 `fav` 里，柜台点单和订单小费都认这个 |

**信任有什么用**：多品类的概率从 40% 往上抬（上限 75%），也就是熟客会点更大的单；
小费按「准时 + 送对口味」给，费率随信任从 4% 涨到 8.5%，送错口味打四折。

**地点也有脾气**。22 个送货点各有一份需求画像（`data.js` 的 `DEMAND`）：

| 地方 | 要什么 | 客单价 | 迟到 |
|---|---|---|---|
| 魔法学院 | 棒棒糖 / 曲奇 / 水果挞 | ×1.1 | 不管 |
| 综合市场 | 曲奇 / 焦糖 / 蛋糕 | ×1.4 | 不管 |
| 议会办公楼 | 马卡龙 / 蜂蜜坚果糕 / 虹彩糖 | ×1.5 | 迟到就退单 |
| 地下拍卖会场 | 同上，越贵越好 | ×1.6 | 迟到退单 |
| 观景台 | 虹彩糖 / 马卡龙 | ×0.7 | 不管 |

所以「送哪儿」第一次开始影响「送什么、值不值得跑、要不要赶时间」。
想加新地点：在 `LOCATIONS` 加一栋楼 → `DELIVER_LOCS` 加 id → `DEMAND` 加一份画像 →
`CUSTOMERS` 加一个住在那儿的人。四步齐全，这个地址才会真的出现在订单里。

## 开局：序章 → 新手教学 → 第一天

1. **雨夜**：从旧城绕回蜗牛巷。左上角一直挂着指引「躲避搜查的人，进入糖果屋」，
   贴着树影走，别进守卫的扇形视野。
2. **进店之后**：面板右栏出现「先完成序章：把盒子放进工作室」。
   这时候**翻不了阶段**——时间被卡住，直到你按下收银机旁的瓷砖。
3. **序章收尾**：自动进新手教学。给你一批原料（砂糖 8、面粉 4、黄油 2），
   并挂一张固定的今日待办：报摊大爷要 **5 支星星棒棒糖**（货架上只有 3 支，得自己开一炉）。
4. 三步走完，教学结束，第一天正式开张：**做够 5 支 → 装上车 → 送到公交总站**。

教学里那张订单是**不能叫第三方代送**的，不然整段送货课就被跳过了。

## 压力的来源：三条软失败线

糖果屋是母亲留下的安全网，**不会倒闭**。所以压力不能来自「活不下去」，
只能来自「配不上更好的机会」。三张会掉分的执照：

| 线 | 怎么掉 | 怎么养回来 | 掉下去会怎样 |
|---|---|---|---|
| 履约信誉 | 超时 −1.2 / 退单 −2.5 / 过期 −2 | 准时送到 +0.5 | 接不到高单价单，评级上不去 |
| 经营合规 | 年检欠费 −15 / 账上透支 −2 每天 | 年检通过 +4、保养 +1 | 执照「待检」，门槛全卡住 |
| 供应链信用 | 赊账逾期 −10 | 结清货款 +3 | 赊账额度缩水，进货变难 |

三条线每天自然回 0.25，但**只回到初始值**（70 / 80 / 70）——
想超过起始值，只能靠做事。跌破 30 会在账本上标红：那是「这一行已经接不到好单」的信号。

## 评级：D → S

每 **7 天**考核一次，看两个数：三条线的均值、这一周赚了多少。

| 评级 | 名字 | 执照均值 | 周流水 |
|---|---|---|---|
| D | 巷口小摊 | — | — |
| C | 有招牌的店 | ≥ 52 | ≥ 1200 |
| B | 新都小有名气 | ≥ 64 | ≥ 2600 |
| A | 城里叫得出名字 | ≥ 76 | ≥ 4800 |
| S | 新都的糖 | ≥ 88 | ≥ 8000 |

达标升一级；连当前级别的底线都守不住就掉一级（D 兜底）。评级管这几扇门：

- **慕名单**（高价急单）要 C 级才出现——门面不够，人家不知道你在这儿
- **配方书**：书价 ≥ 800 要 C 级，≥ 1200 要 B 级
- **载具**：厢型车要 C，小货车要 B
- 订单簿上限随评级 +1 格

**低评级不会死，只会慢。** 你可以一直苟在蜗牛巷，但外面的单子不会来找你。

## 现金可以是负数

打烊扣账时钱不够，账上直接变负——**不会结束游戏**。透支期间：

- 买不了原料、升不了级、雇不了人、买不了书、保养不了设备
- 但**可以卖货、可以接单**，做正了就缓过来
- 手上一件货都没有的极端情况：去**巷口帮半天忙**，一天一次、花 1 点行动点，
  换面粉 ×2 + 砂糖 ×1 + 黄油 ×1——正好够开一炉黄油曲奇，重新开张。
  （母亲失散多年，主线就是在找她，所以这里没有「跟妈要钱」这条路。）

## 批发采购：不用自己跑市场

库存页底部有「发起采购」。给批发商下单，他备货、送货，你只要等：

| 项目 | 规则 |
|---|---|
| 批发价 | 单价比门市便宜 **15%** |
| 满量再折 | 10 份 −3% / 20 份 −6% / 40 份 −10% / 60 份 −15%（取最高一档） |
| 跑腿搬运费 | 12G 底费 + 货值的 6% |
| 到货 | 隔 **2 个阶段**（至少跨过一个阶段）才送到，跨天也算得准 |

它和「自己跑一趟水果摊」是两条路：跑一趟省的是钱（门市价但没中间费），
发一次采购省的是**时间和行动点**。前期现金紧，还是自己跑划算；单量上来之后采购才真正值。

## 外卖与路上那点事

**外卖终端**：第 3 天、信誉 55 之后，店铺页花 **680G** 开通。坐班时平台推单，
订单簿底部出现「外卖单」区块——和常规配送**不互通**，不占运力、不用出门。
货架上有货就点「放入取餐口」（1 AP），收班时骑手来取，平台抽 20% 后到账。
没雇助手时得自己盯，漏单掉信誉和履约；雇了学徒，她收班前会自动备好最多 2 单，
漏单也不扣信誉——这就是「用助手换一份自动化收入」。

**路上事件**：常规配送每烧 1 点行动点都可能遇到事，城南、码头这类危险城区概率更高，
一个阶段最多两回。弹窗期间地图暂停，选完才继续。选项会真改行动点、元气、现金、信誉、
三条软失败线，甚至从车厢里顺走一件糖（到地方就会缺货）。11 种事件里有两条会把你推进
**战斗**（影狼组收过路费、议会巡检机）。自测页和 `?noevent` 下不触发。

**战斗**：不是打怪升级，是一场临时冲突。血量由当时的元气推出来，一回合选一个做法——
抡过去、架住（减伤六成）、扔一盒糖（砸晕对方一回合）、吃掉一颗糖（回血回元气）、掉头跑。
打完把损耗折回元气：赢了拿钱和原料，输了丢 60G、掉 3 信誉、还少一盒糖。
战斗整份进存档，读到半途的档能接着打；没分出结果时 ESC 关不掉弹窗。

**深夜事件**：只在睡前（21:00 之后）来，一晚至多一回，和白天路上事件互不占次数。
代价多落在元气、库存和三条线上，不会把睡前那 3 点 AP 全吃掉。有的选项会记成熬夜
（次日元气不满）、探明一处管网出口，或者把屋脊上的影子引下来打一架。
随机没碰上也可以花 1 AP「再听一听巷子」主动撞一件。

## 结档：把这一档封存起来

存档面板（右上「存」）底部有 **结档**。结档不是失败——糖果屋不会关，
只是这一档到此为止：留一张成绩单（天数 / 评级 / 累计营业额 / 卖出多少件 /
送达多少单 / 认得多少人 / 三条线的最终值），然后开新的一档。

成绩单按评级给一句评语，从「糖果屋还亮着灯」到「别人拿糖果屋当坐标」。
封存记录存在本地（最多 10 档），**手动槽位不会被动**。

## 钱花在哪：店铺与配方书

现金压力不靠房租堆，靠三样东西：**设备状态、执照年检、供应商赊账**。

### 每天固定扣的

| 项目 | 多少 | 说明 |
|---|---|---|
| 家用 | 当日营业额 12%，保底 40G | 母亲立的家规：柜上进来多少，抽一成给家里 |
| 水电 | 每件成品 2G | 只看当天**做出来**多少件，废掉的不算 |
| 工钱 | 学徒日薪合计 | 0 / 40 / 80 / 110 / 140 看你雇了谁 |
| 执照年检 | 480G / 每 28 天 | 到期那天并进账单，交不出就掉合规 |

**这间屋子和铺面是米莉母亲的产业，不存在房租。** 母亲只要「家用」——
按营业额抽成而不是按天收租，所以生意好的月份多分担，冷清的日子也不逼你；
小费不算在里面（那是客人塞给米莉自己的）。

### 设备状态：不理它就变差

每做一件成品磨损 +0.5（烤炉等级越高越省：×1 / ×0.8 / ×0.6），
磨损吃成功率，磨满 −35%。年检时设备太脏还会扣合规。

保养费 = 30 + 磨损 × 4，随时可以清到 0。**拖着不修是最贵的**——
它同时吃掉产能和合规，两样都要花钱补。

### 供应商赊账：钱不够也能开工

现金不够进货时自动转赊账，额度 = 供应链信用 × 600G 上限，账期 3 天。
到期自动从账上扣：结清 +3 信用，扣不出就顺延两天、−10 信用、额度跟着缩。

赊账是「活过这个礼拜」的手段，不是免费的额度——它把现金流压力
挪到了供应链信任这条线上。

### 一次性投入

| 升级 | 三级效果 | 价钱 |
|---|---|---|
| 柜台 | 同时 2 → 3 位客人，补位从 ×1.0 到 ×2.4 | 1200 / 3200 |
| 展示柜 | 零售 +6% → +14%（同一个品卖得更贵） | 900 / 2600 |
| 烤炉 | 糊了退回一半原料 → 全退，且高档品省 1 AP | 1500 / 3800 |

烤炉那条要说清楚：满元气制作成功率本来就是 100%，所以「提高成功率」是假效果。
改成**糊了退料**之后，做虹彩糖（原料 57G）那种单子才真的不怕翻车。

### 助手坐班：把柜台交出去

雇来的学徒可以安排到**柜台**（店铺页 → 帮工 → 安排看柜台）。之后坐班时，
柜台左下角会亮起 **「交给小X看着，出门 →」**：

- 点了就进大地图，这一班你可以去送货、跑主线、闲逛
- 收班时她按**柜台价九折**替你卖掉一批货（件数 = 她的 AP × 2 + 2）
- 卖得比你自己便宜，而且**不涨熟人信任**——客人只记得糖好吃，记不住是谁卖的
- 货架空着的话，她只能一直跟客人道歉（信誉 −0.5）

这是「用助手换时间」的完整闭环：她的 AP 你本来就能用，但把柜台交出去之后，
**同一段时间你能做两件事**。

### 第三方配送：用钱买时间

订单页每单都有 **代送** 按钮：平台上门取货、准时送达、路上不会遇到任何随机事件。

| 项目 | 规则 |
|---|---|
| 抽成 | 尾款的 45%，最低 12G |
| 前置 | 货必须已经做出来（平台只送，不做糖） |
| 效果 | 立刻完成这单：尾款到账、履约 +0.4、信誉 +0.8、熟客信任只 +0.05（不是米莉本人送的） |
| 代价 | 没有小费，而且吞掉近一半的尾款 |

前期它基本等于亏本，意义是**救急**：明天到期、你今晚 AP 已经见底的那一单，
花 40% 换一个不掉履约，是划算的。

## 主线：糖衣下面

主线不在订单簿里，走的是后场左侧的**「委托」**页。那一页会告诉你现在走到第几步、
目标是什么、手上有哪些线索和东西，下面还有一份章节目录。

**序章 · 银色纽扣糖** — 雨夜，你带着不该拿的东西逃回蜗牛巷。这一章是潜入教学：
巷子里有两个巡逻的人，避开他们的视野绕回糖果屋后门，再在店里按下收银机旁的瓷砖，
打开母亲的暗门工作室。

**第一章 · 草莓夹心与失踪学生** — 一位母亲带着一枚雪花胸针和十二颗草莓夹心糖上门，
她女儿在魔法学院失踪了。按委托页上的步骤走：回想胸针里的残影 → 去银狐酒吧后巷 →
从铁门下去把人带出来 → 回店安顿她。

**第二章 · 薄荷硬糖与加密数据** — 第一章过去两天后，埃文抱着一个烧掉读取仪的金属盒上门。
破解 → 回银狐酒吧后巷取回没搬走的实验记录 → 把三张图叠起来 → 黑信封里的渡鸦卡片 →
熬一炉薄荷硬糖。这一章把「蓝色烙印」「地下管网」「七个锚点」串成同一套工程，
也第一次点出母亲失踪前在查什么。走完自动接第三章。

**第三章 · 焦糖布丁与黑手党晚宴** — 渡鸦说的「老地方」是码头第七仓库顶层：母亲的旧档案、
五十年前就开始的三步计划、以及一句「她还活着」。第二天上午维斯孔蒂上门签下影狼组生日宴的
甜品单。按委托页走完六步：赴约 → 签合同（上午坐班时自动上门，预付 800G）→ 备一箱宴会糖
（2 AP / 60G）→ 前往银月庄园（3 AP，偷听到「通道」和「大收割」）→ 上二楼书房拍图纸（2 AP）
→ 回店敲开留给自己的那份焦糖布丁。这一章点明新都塔就是第七锚点，也是闭合环的那一扣。

**第四章 · 柠檬酸糖与背叛助手** — 镜头拉回糖果屋。兼职生小源回来上班，也是这一章
**给你带来一位助手**：走完第一步他就进店，之后能排柜台或跑配送。可他这周不对劲——
偷看手机、盯特定订单、在巷口和穿深色夹克的男人低声说话。按委托页六步查下去：
闭店后检查取件口（显影粉与隐形药水，浮出「包裹内含追踪器」）→ 回放镜像水晶与巷口
集音录音（妹妹小悠被拿来胁迫，米莉自己也被监视）→ 用通讯石确认小悠手腕上的螺旋手链
→ 后厨摊牌，递出掺了解药的蜂蜜蛋糕 → 布下明天的局。这一章第一次点出「螺旋纹身的
第三方势力」，也让米莉从被动查案转为主动走一步棋。

第四章走完之后，主线回到自由经营，第五章起待写。剧情全程走委托页按钮与剧本，
不新造地图；宴会、书房和店内调查都是「一段叙事」，不用再找路。

### 潜入怎么玩

| 元素 | 说明 |
|---|---|
| 视野扇形 | 守卫身前那片半透明区域。进去就涨警觉，离得越近涨得越快 |
| 警觉度 | 顶部那条。涨满就被抓住——不删档，退回起点重来 |
| 蹲下 | `Shift` 或底部按钮。走得慢，但被看见的距离缩到六成 |
| 扔糖 | `Q` 或底部按钮。把附近的守卫引到糖落下的地方，趁机过去 |
| 藏匿点 | 地上那圈暗色。站进去，警觉掉得更快 |

被抓不是失败：序章扣 4 点元气，第一章扣 1 点信誉，然后回到起点重来。

## 字体

界面用 **破晓像素（PoxiaoPixel）**，一款 12px 等宽像素字体，由 diaowinner / Poxiao Labs 制作，
基于 Fairfax、ZLabs Bitmap、Galmuri 三款上游字体整合而成。

- 授权：**SIL Open Font License 1.1**，个人与企业均可免费商用、嵌入、再分发
- 收录：简体 6763 字 / 繁体 8496 字，共 57421 个字符
- 上游：<https://forge.poxiao-labs.work/Fonts/fzg>
- 本地文件：`assets/fonts/poxiao/`（70 个 woff2 分片，共约 2.0 MB，按 unicode-range 切分按需加载）
- 授权正文：`assets/fonts/poxiao/OFL.txt`

**改字号时注意**：这是 12px 网格字体，字号取 12 的整数倍（12 / 24 / 48）才不会有像素被重采样。
小于 12px 会直接丢掉像素行，糊成一团。当前样式已把所有字号收敛到 12px，只有少数标题用 14–16px、
主标题用 48px。`canvas` 里的文字（地图标签、店面招牌）同样遵循这条规则。

## 打包发布

双击 **`build.bat`**，产物是 `dist/candy-house.html`——一个文件，双击就能玩，
丢到 GitHub Pages / 对象存储 / nginx 也直接能跑（不需要任何服务器逻辑）。

```
build.bat           全内联，约 3.0 MB（含着 70 个字体分片）
build.bat nofont    不内联字体，约 200 KB（回退系统字体）
```

等价于手工执行 `node tools/build-single.js [--no-font]`。脚本做的事：

1. `<link rel="stylesheet">` 全部读进来内联，CSS 里的 `url()` 逐个转成 base64；
2. `<script src>` 按原顺序内联，顺带转义掉可能提前闭合标签的 `</script>` 字面量；
3. 收尾检查还有没有漏掉的外部 `src` / `href`，有就列在终端里。

**改完源码要重新跑一次**，`dist/` 里的是快照，不会自己更新。

- **改装 / 产业 / 自提：`src/data.js` 的 `VEHICLE_MODS` / `BASES` / `PICKUP`**（价钱、评级门槛、效果增量、每阶段产量、自提单比例）

- **战斗：`src/data.js` 的 `COMBAT`**（玩家四项基础数值、`fleeChance`、输赢代价、`enemies` 各自的血量攻防与战利品；回合结算在 `src/engine.js` 的 `battleAct()`）
